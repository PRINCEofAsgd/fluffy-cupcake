# 版本说明

## Web

- 当前版本：`V1.1.0_20261116`
- 发布域名：`https://fluffy-cupcake.cn`
- 整体功能：提供个人 Homepage，以及轻量、响应式的“想念按钮”、陪伴绑定、心情与双向记录页面，支持固定用户密码登录和二维码卡片扫码登录。

### 本次更新

- 密码和扫码登录均可保持 15 天，期间按需恢复登录。更新上线后，已登录用户需重新登录一次。
- 想念统计默认显示“ta想我”，可切换到“我想ta”。
- 心情与想念统计共用视角。统计区的铅笔可编辑自己的心情，并进入备注设置。
- 影响原因新增「好运」，原因和安慰均已配齐图标。
