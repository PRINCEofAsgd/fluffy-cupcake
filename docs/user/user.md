# 操作手册

## 访问与登录

- 本地开发：`http://localhost:4819/yanlili`
- 正式环境：`https://fluffy-cupcake.cn/yanlili`

根路径 `/` 会自动跳转到 `/yanlili`。未登录不影响按钮动画和音效，但点击只显示“按按钮，想你+1”，不会保存。页面右上角提供登录入口，项目不提供公开注册或找回密码。

## 陪伴绑定与收件箱

“陪伴绑定”入口始终保留到绑定成功。未登录时点击会提示“该功能需登录后使用”，并展开登录区。登录且未绑定时可输入目标用户名和可空备注发送邀请；不能绑定自己，双方任一已有活跃绑定时不能新建或接受绑定。

邀请方和收信方都能在“收件箱”看到同一封信件。收信方接受后完成双向绑定，双方页面上的绑定入口消失；信件永久保留且没有删除操作。因其中一方接受其他邀请而冲突的待处理信件会保留为“已失效”。

绑定后可通过“修改备注”设置自己看到的对象名称，留空恢复显示用户名。备注只属于修改者，不会覆盖对方的备注。

解绑也在原绑定信件中完成：一方先发起解绑邀请，另一方在同一封信中接受后才会双向解绑。若对方最近一次登录已超过 30 天，可使用信件中的直接解绑；不满足时间条件时服务端会拒绝。解绑只结束当前关系，不删除信件和想念历史，此后双方可与其他用户绑定。

## 使用想念按钮

点击、轻触或聚焦后按 Enter/空格都会立即产生上浮文字和约 90ms 的合成短音。未登录或未绑定时宾语固定为“你”；双向绑定后宾语为绑定对象用户名，设置备注后优先使用备注。

只有登录且双向绑定后，点击才会以约 750ms 批量同步到当前关系的“我想 ta”方向。同一方向同一分钟点击多次只占一个分钟桶，但次数完整累计；同步失败会保留待发送数量并轻量重试。

## 当前与详细记录

当前绑定的记录框标题为“我想ta”或“ta想我”。标题旁只有一个 ⇄ 切换按键；“每日想念”和“最近想念”分别由数据库按新到旧返回最新 8 条，分钟时间按浏览器本地时间显示。

“详细记录”可在历次已经接受绑定的用户中选择一个对象，查看双方所有有对象的分钟记录。每页 20 条，按时间从新到旧排列，并标明“我想ta”或“ta想我”。同一用户对的历次绑定不会分段展示；明确补录了对象的迁移旧数据也会并入同一列表，但不会额外生成收件箱信件。
