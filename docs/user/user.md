# 操作手册

## 访问页面

- 本地开发：`http://localhost:4819/yanlili`
- 正式环境：`https://fluffy-cupcake.cn/yanlili`

根路径 `/` 会自动跳转到 `/yanlili`。

## 登录与退出

页面右上角提供独立登录入口。未登录不影响按钮使用，但点击只产生当前页面的文字和音效，不保存、也不展示数据库统计。输入管理员人工创建的固定用户名和密码后，浏览器会保存 HttpOnly 认证 Cookie；此后点击才会持久化，页面下方也会显示共享统计。右上角可退出，退出会清除 Cookie。项目不提供公开注册或找回密码页面。

## 使用按钮

点击或轻触页面中央的 GIF 按钮，每次都会立即出现一行“按按钮，想哥哥+1”，文字向上漂浮后渐隐；浏览器会为每次点击合成一段约 90ms 的短促提示音。快速连续点击的声部可以重叠，不会下载、解码或等待 MP3，也不会阻塞文字动画。

使用键盘时，先通过 Tab 聚焦按钮，再按 Enter 或空格即可触发。页面会遵从系统“减少动态效果”设置。

登录状态下，快速点击会在约 750ms 内合并发送；失败的数量会保留并做轻量重试。页面下方显示所有登录用户共享的总点击数、UTC 每日次数，以及按分钟合并的最近点击时间；同一分钟点击多次只出现一个时间点，但 count 会完整累计。
