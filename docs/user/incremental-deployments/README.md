# 局部更新部署

[部署指南](../deployment.md)记录长期适用的部署方法。本目录按最近一次确认部署的 Web 版本维护增量手册，供已有环境从该版本更新到当前待部署版本。

## 维护规则

- 文件名为 `from-V<主版本>.<次版本>.<修订版本>_<日期>.md`。文件名中的版号是已部署基线，文首同时列出目标版本和适用的数据库版本。
- 同一基线尚未切换时，继续在原文件维护从该基线到当前目标的累计步骤。用户明确确认完成部署后，以新部署版本为基线建立下一份手册。
- 每份手册写明变更范围、部署前核对、数据库迁移与应用切换顺序、环境变量、验证标准和失败回退。凭据通过平台 Secret 提供。
- 部署执行情况以实际确认结果为准。历史手册保留原基线及目标。
